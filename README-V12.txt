OP17 Simulator V12

Changements :
- Le titre visible et l’onglet navigateur s’appellent maintenant simplement « OP17 Simulator ».
- Ajout d’un bouton « Réinitialiser » en haut à droite.
- Confirmation obligatoire avant effacement.
- Le reset efface uniquement les données locales OP17 : boosters ouverts, collection, tapis, display, mode et préférences.
- Les autres données localStorage éventuellement utilisées par d’autres projets localhost ne sont pas touchées.
- La V12 conserve les derniers visuels ALT/DON ajoutés dans la V11.7.2.
