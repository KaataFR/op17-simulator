# OP17 Simulator V13 — Sound Design

V13 ajoute une couche sonore légère et hiérarchisée :

- ouverture booster : déchirure/foil (`pack_rip.wav`)
- swipe carte : frottement court (`card_swipe.wav`)
- pose/reposition sur tapis : contact feutré (`card_place.wav`)
- UI : clic doux (`ui_click.wav`)
- classeur : page papier (`page_turn.wav`)
- SR / SEC / ALT / SP / TR : scintillement (`rare_sparkle.wav`)
- Manga / Super Alt / Super Alt Red / Super Leader : whoosh premium (`premium_whoosh.wav`)
- fin de display : stinger de réussite (`display_success.wav`)
- bouton haut-droite pour couper/réactiver les sons

Les fichiers audio inclus dans cette build sont générés localement pour le projet et n'ont aucune dépendance réseau. La direction sonore a été étudiée à partir de packs CC0 de Kenney/OpenGameArt et de banques de SFX courts.
